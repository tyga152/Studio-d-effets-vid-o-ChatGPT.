Studio d’effets vidéo — Adaptation pour ChatGPT

Présentation

Ce projet vise à adapter les 51 effets vidéo du dépôt "claude-video-effects" (https://github.com/Vibha-Ramprakash/claude-video-effects) afin de préparer un environnement de travail exploitable avec l'assistance de ChatGPT.

Objectifs

- Documenter les 51 effets vidéo.
- Concevoir des séquences et des montages.
- Générer des plans de montage au format JSON.
- Adapter les instructions au fonctionnement de ChatGPT.
- Intégrer progressivement le moteur Python et ses ressources.
- Préserver les licences et les attributions originales.

Documentation

- "CATALOGUE_EFFETS.md" : catalogue des 51 effets.
- "INSTRUCTIONS_CHATGPT_ADAPTEES.md" : instructions de travail.
- "STRUCTURE_PROJET.md" : organisation du projet.
- "CONTROLE_TECHNIQUE_COMPLEMENTAIRE.md" : analyse technique.
- "INSTALLATION_MOTEUR.md" : installation.
- "FORMAT_PLAN_JSON.md" : format des plans.
- "STATUT_PROJET.md" : avancement.
- "RESSOURCES_MANQUANTES.md" : éléments restant à intégrer.
- "exemple_plan.json" : exemple de plan.

État du projet

La documentation initiale est préparée et publiée.

Le moteur Python, ses dépendances, les polices et les modèles restent à intégrer et à tester.

Aucun rendu vidéo n'est déclaré fonctionnel tant qu'un test réel n'a pas été effectué.

Prérequis techniques

Le rendu vidéo réel nécessite notamment :

- Python 3.10 ou supérieur ;
- FFmpeg et FFprobe ;
- les dépendances Python du moteur ;
- les ressources nécessaires aux effets utilisés.

ChatGPT peut préparer les instructions et les plans de montage, mais ne lance pas automatiquement le moteur vidéo.
